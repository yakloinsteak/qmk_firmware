# kinesis_kintrp2040 keyboard firmware

RP2040 conversion of the kinT Kinesis Advantage controller. Hardware design lives in
the `kint` repo; see https://github.com/kinx-project/kint for the original kinT.

Flash by holding BOOT while plugging in USB, then copying
`.build/kinesis_kintrp2040_<keymap>.uf2` to the `RPI-RP2` drive.
